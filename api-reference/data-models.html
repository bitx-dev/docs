This generated reference lists the exact field names and types in the backend models used by the integration APIs. Use the endpoint guides for HTTP status, envelopes, defaults, and service behavior. Download the field contracts.

Names are case-sensitive. JSON fields without omitempty remain present when empty or zero; pointers can be null. A Go time.Time is encoded as an RFC 3339 string and can remain present even with an omitempty tag. Array/map fields without omitempty can be null when uninitialized. Shared request validation tags describe declared constraints; controller/service behavior determines which are enforced. Request optionality is not implied by the response serialization column.

Webhook event data has its own complete reference; webhook management responses below are not the data object of an event. Engine amounts are decimal strings in base units in the engine response, while compatibility checkout uses display numbers for top-level amount fields.
